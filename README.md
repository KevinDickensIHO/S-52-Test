# S-52-Test
This is a test repository for S-52 used to help highlight how issues will be managed with multiple repos via a project dashboard

# Issues
All issues are managed in the root ENCWG repository (This repo) and must be submitted with appropriate flags for the product specification and the type of work

🔶🔶🔶 All issues opened should contain no less than 2 labels.  On should be a product label and the second should be a document label.  This way everyone can see both the standard(s) impacted as well as the type of work being referenced. 🔶🔶🔶

## Issue Labels
This list of approved labels is located here:

### Product Labels
⬜ S-52 Specifications for Chart Content and Display Aspects of ECDIS.

### Document Labels
🟦 Main Document | Any issues concerning the main document of the standard or product specification.

🟨 Annex | Issues concerning Annexes of the standard or product specification.

⬜ Presentation Library | Issues concerning the Presentation Library.

### Work Labels
🟥 Extension | Significant changes that introduce completely new features, modules, or attributes to the specification or remove such things.

🟨 Correction | Substantive semantic changes that rectify factual errors or address practical implementation anomalies within existing specifications.

🟦 Clarification | Non-substantive semantic changes that remove ambiguity, correct grammatical/spelling errors, or update cross-references.
